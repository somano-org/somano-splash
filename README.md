# `somano-splash` Plymouth Theme
- The splash theme for somano forked from the Spinner theme from plymouth themes
- jimmac was the creator of the original spinner theme

> This project is still in alpha, it's a W.I.P.

### Installation
1. Copy the `somano-splash` folder from the git cloned repo into `/usr/share/plymouth/themes/somano-splash`.
2. Apply the theme.
